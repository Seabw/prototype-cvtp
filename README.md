# Cash Vortex: Triple Power™ - Interactive Web Prototype

A standalone, interactive browser prototype showcasing the mechanics and mathematical model of **Cash Vortex: Triple Power™**.

## Features Demonstrated

- **5×5 Dynamic Symbol Grid**: Persistent cash coin counters with 1–3 lifespans.
- **Strike & Vortex Cash Collections**: Instant collection mechanics for active on-screen coin values.
- **Dynamic 3-Pot Accumulator**:
  - **Pot 1 (Mini Wheel)**: Multipliers & Strike enhancements.
  - **Pot 2 (Mega Wheel)**: Multipliers & Vortex collections.
  - **Pot 3 (Ultra Wheel)**: Multipliers, Lock & Slingo triggers, and isolated Progressive Jackpots.
- **Geometric Skip Pot Trigger Rule**: Mathematically calibrated dynamic pot trigger weights.
- **Lock & Slingo Respin Bonus**: Respin grid with 12 lines, slingo progression, and cash awards.
- **Procedural Audio Synthesizer**: Web Audio API generated sound effects (coin drops, zaps, whooshes, pot chimes).
- **Math & QA Debug Inspector**: Real-time feature forcing, RTP metrics, and engine log inspection.

## Architecture

Pure client-side HTML5, Vanilla CSS3, and ES6 JavaScript modules with no external build tools or runtime dependencies required.
